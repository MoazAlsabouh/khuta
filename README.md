# خُطى | رفيقك نحو التفوق

أهلاً بك في **خُطى**! 👋  
تمت ترقية المنصة بالكامل لتصبح **تطبيق ويب تقدمي فائق (Super Web App / PWA)** يجمع بين أعلى معايير تجربة المستخدم، أدوات الإنتاجية الذكية، والعمل بدون إنترنت لتكون رفيقك الأقوى نحو التفوق الدراسي.

---

## 🌟 أبرز الميزات والخدمات الفائقة

### 1. 📲 تطبيق ويب تقدمي متكامل (PWA)
- **قابل للتثبيت على كافة الأجهزة:** ثبّت المنصة كتطبيق أصيل على شاشة هاتفك (Android / iOS) أو حاسوبك (Windows / Mac) بنقرة واحدة عبر زر «📲 تثبيت».
- **العمل في وضع عدم الاتصال (Offline Mode):** بفضل تقنية Service Worker المتقدمة، يمكنك فتح جدولك وملاحظاتك ومؤقتك والدروس حتى عند انقطاع الإنترنت، مع شارة ذكية توضح حالة الاتصال لحظياً (🟢 متصل / 🔴 أوفلاين).
- **أيقونة وهوية بصرية مخصصة:** أيقونة متجهة عالية الدقة `icon.svg` مع ملف التهيئة الرسمي `manifest.json`.

### 2. 🌙 محرك الثيمات والتصميم العصري (Glassmorphism)
- **الوضع الليلي والنهاري (Dark & Light Mode):** زر تبديل سلس (🌙 / ☀️) يحفظ خيارك تلقائياً في المتصفح لتجربة مريحة لعينيك أثناء الدراسة ليلاً.
- **تصميم زجاجي عصري (Glassmorphism):** بطاقات تفاعلية بتدرجات راقية، تأثيرات تحويم ناعمة، وخطوط تقدم متوهجة.
- **شريط تنقل سفلي للهواتف (Mobile Bottom Bar):** تصفح سهل ومريح بالإبهام بين جميع الأقسام.
- **مؤثرات صوتية ذكية (Web Audio API):** نغمات إنجاز تشجيعية نقية وممتعة تعمل فوراً عند إنهاء المهام، تقليب البطاقات، أو اكتمال مؤقت التركيز (دون الحاجة لتحميل ملفات خارجية).
- **نظام إشعارات عائمة (Toast Notifications):** رسائل تشجيع وتأكيدات فورية وجميلة لكل عملية إنجاز أو حفظ.

### 3. ⚡ حزمة الأدوات الدراسية الفائقة (Super Tools Suite)
قسم مخصص في شريط التنقل باسم **«الأدوات الذكية ⚡»** يضم:
- **🎯 مؤقت بومودورو للتركيز (Focus Pomodoro):**
  - عدّاد دائري مرئي مع 3 أوضاع: تركيز (25 د)، استراحة قصيرة (5 د)، وراحة مطولة (15 د).
  - **مصغّر حي في الشريط العلوي:** تابع المؤقت وشاهده يعد تنازلياً في أعلى الشاشة وأنت تتصفح جدولك أو موادك أو امتحاناتك!
  - تنبيهات صوتية وإشعارات للمتصفح مع عدّاد جلسات الإنجاز اليومية 🔥.
- **🧠 بطاقات الاستذكار السريع (3D Flashcards):**
  - بطاقات ثلاثية الأبعاد تنقلب بسلاسة وتأثير صوتي عند النقر.
  - أزرار تقييم الحفظ (عرفتها ✔️ / أحتاج مراجعة 🔄) مع إمكانية إضافة بطاقاتك الخاصة وحفظها محلياً.
- **🎯 أولويات وأهداف اليوم (Daily MIT Checklist):**
  - ركّز على أهم 3 أهداف لليوم مع شريط تقدم مستقل لإبقائك في قمة الحماس.
- **📝 المفكرة السريعة (Auto-Save Quick Notes):**
  - مفكرة ذكية لتدوين الملاحظات والمعادلات مع ميزة الحفظ التلقائي اللحظي، عدّاد الكلمات والحروف، وزر للنسخ المباشر بنقرة واحدة.

### 4. 📊 تتبع الإنجاز الدراسي وجدول الأسبوع
- نسبة الإنجاز العامة في كل مادة والمراحل الدراسية الخمس (الدراسة الأولى، المراجعة الأولى، المراجعة الثانية، مراجعة التثبيت، المراجعة الامتحانية).
- جدول أسبوعي ذكي يتجدد تلقائياً كل يوم جمعة دون فقدان سجل النشاط السنوي.
- لوحة نشاط السنة (52 أسبوعاً) بمربعات خضراء تشبه لوحات المطورين العالميين.
- عد تنازلي دقيق للامتحانات ومكتبة خاصة لقنوات ومصادر الشرح المفضلة لكل مادة.

## 💡 كيف أبدأ؟

1. **سجّل الدخول:** باستخدام بريدك الإلكتروني أو حساب Google بنقرة واحدة.
2. **اختر فرعك:** (علمي أو أدبي) لتعرض لك المنصة المواد المخصصة لفرعك فقط.
3. **ثبّت التطبيق:** اضغط على زر «📲 تثبيت» في الشريط العلوي لتثبيت المنصة على جهازك.
4. **ابدأ جلسة التركيز:** شغّل مؤقت بومودورو، حدد أهدافك اليومية الثلاثة، وانطلق نحو التفوق!
